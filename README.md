# Забавоград — единый публичный проект

**Основной репозиторий:** `afevina-lab/zabavograd-demo`. Здесь находятся редакторская библиотека, правила отбора слов, семантический граф, исходники игр, оформление, инструменты и документация. Второй репозиторий **не нужен** для редактирования и сборки. Ветка `main` — источник; `gh-pages` — только публикация сайта [Забавоград](https://afevina-lab.github.io/zabavograd-demo/).

## Как работать дальше

Редактируйте `outputs/library-v2.json` непосредственно в `main` публичного репозитория или через отдельную ветку и Pull Request. Веса — `100 / 70 / 50 / 30 / 20 / 10`, ноль исключает из базовой выдачи; специальные веса упражнений хранятся отдельно. Не менять ID при переименовании и не связывать неоднозначные иллюстрации без проверки. Структуры лексической темы, родового понятия, смысловой связи, грамматической роли и картинки различаются.

Для локальной разработки:

```sh
npm install
npm run dev
npm test
npm run check:library
npm run check:design-system
npm run build
npm run library:refresh
```

Редакторский просмотр генерируется в `outputs/Библиотека.html`; отдельные редакторы предложений — `outputs/Проверка-смысловых-связей.html`, `outputs/Модели-действия.html`, `outputs/Значения-RuWordNet.html`. Библиотечные программы — в `scripts/`. Формы слова и фонетические свойства не угадывать без сохранения статуса проверки.

Утверждённый игровой JSON формируется из V2 скриптом `scripts/export-library.cjs`. Сайт потребляет только локальные статические JSON и WebP; он не вызывает FrameBank, Конструктикон, RuWordNet, Wikidata или языковые модели во время работы. Публикация `gh-pages` производится только из проверенных данных этого репозитория, без источников во втором репозитории.
