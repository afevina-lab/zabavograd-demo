# Забавоград — единый публичный проект

**Основной репозиторий:** `afevina-lab/zabavograd-demo`. Здесь находятся редакторская библиотека, правила отбора слов, семантический граф, исходники игр, оформление, инструменты и документация. Второй репозиторий **не нужен** для редактирования и сборки. Ветка `main` — источник; `gh-pages` — только публикация сайта [Забавоград](https://afevina-lab.github.io/zabavograd-demo/).

## Единая библиотека — модульное хранение с 27 ноября 2026 года

- `outputs/library-modules/` — единственный редактируемый источник: 1 993 записи, 1 540 отношений и 234 категории на момент перехода. `editorial/library-source-mode.json` фиксирует канонический режим.
- `library.json`, `semantic-graph.json`, `public/grammar-frames.json`, HTML и SQLite — производные; вручную их не редактировать. Старый `outputs/library-v2.json` удалён, не восстанавливать рядом.
- Сохранять устойчивые ID, смысловые значения, формы, фонетику, веса и проверенные связи с изображениями. Непроверенные предложения не считать утверждёнными. Игры используют статические ресурсы, без сетевых лингвистических сервисов во время занятия.

История объединения: [отчёт сверки 12 ноября](docs/consolidation-audit-20261112.json), [переход на модульное хранение](docs/LIBRARY_CUTOVER.md). Приватный предшественник не является источником разработки; резервные точки объединения описаны в истории Git и отчётах.

## Как работать дальше

Для точечной работы с библиотекой использовать `npm run library:tool -- find|inspect|select|gaps|inventory` и протоколы [локального инструментария](docs/LIBRARY_TOOLKIT.md) и [удалённых запросов](docs/LIBRARY_REMOTE.md). Правки — пакеты по ID с предварительной проверкой, а не редактирование производных JSON. Веса: 100 / 70 / 50 / 30 / 20 / 10; ноль исключает из базовой выдачи. Не объединять омонимы автоматически.

Для локальной разработки:

```sh
npm install
npm run dev
npm test
npm run check:library
npm run check:design-system
npm run build
npm run library:refresh
```

Редакторские HTML формируются из канонического источника. `scripts/export-library.cjs` формирует игровой JSON. Публикация `gh-pages` собирается из проверенного `main`.
