# Превращения — концепция флэш-карточек

Цикл: исходная карточка → задание → ответ ребёнка → подтверждение взрослым → тематическое превращение → итоговая карточка.
Игра не оценивает произношение автоматически. В устном режиме педагог нажимает «Показать превращение»; альтернативы — выбор ответа или чтение с последующим раскрытием.

## Учебные преобразования
- Уменьшительно-ласкательные: кот → котик. Ответ меняет слово, а уменьшение картинки служит визуальным подкреплением: размер сам по себе не проверяет правильность формы.
- Один — много: мяч → мячи, один объект превращается в группу.
- Чтение: слово → соответствующая картинка; ребёнок сначала читает, затем проверяет себя.
- Позже: признаки, действия и противоположности.

## Темы
- Космос: луч сканера, звёздная пыль, предмет собирается заново из частиц; множество появляется как созвездие.
- Лес: листовой вихрь, раскрывающийся бутон или солнечный свет; множество вырастает на полянке.
- Волшебная сказка: взмах палочки и мягкий след искр, затем буквальное превращение.

## Устройство
Учебный сценарий хранит исходное слово, ожидаемый ответ, изображения и тип преобразования. Тема отдельно предоставляет фон, карточки, звук и эффект. Одна задача работает со всеми темами.
Важные состояния: ожидание, показ задания, ответ, подтверждение, превращение, итог. Во время превращения повторный запуск блокируется.
Длительность эффекта 1–1,6 секунды, возможность пропустить, режим без анимации. Неверный ответ сохраняет исходную картинку и предлагает попробовать ещё раз без наказания.

## Первый прототип
Три задания: кот → котик; мяч → мячи; прочитать «дом» → показать дом. Две темы: лес и космос. Для занятий — ручной переход, повтор, подписи и отключаемый звук. Подключение к библиотеке после проверки структуры данных и наличия нужных форм/иллюстраций.
