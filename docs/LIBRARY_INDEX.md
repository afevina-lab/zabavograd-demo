# Компактный индекс редактора (этап 2)

Генератор `node scripts/build-library-index.cjs /tmp/zabavograd-index` читает логический снимок канонических модулей, исторические остатки машинных предложений в карточках, существующий слоговой индекс, runtime для сверки хэша и `editorial/library-tasks.json`. Результат детерминирован, не меняет исходники; выходная папка должна отсутствовать. 

После успешного слияния GitHub Actions публикует **только производный индекс и HTML-просмотр** в ветку `library-index` (не main, не gh-pages); PR получает артефакт предпросмотра. Ветка не является редактируемым словарём. В `preview/Библиотека.html` доступен проверенный автономный HTML, в `preview/Проверка-смысловых-связей.html` — дополнительный локальный инструмент. Для скачивания использовать [ветку library-index](https://github.com/afevina-lab/zabavograd-demo/tree/library-index/preview) либо артефакт `library-index` соответствующего успешного запуска. Локально `node scripts/build-library-v2-view.cjs` и `node scripts/check-library-preview.cjs` создают и проверяют игнорируемый `outputs/Библиотека.html`. 
- `manifest.json`: хэши источников (SHA-256 и Git blob SHA), количества, статусы, список страниц, инвентаризация полей и очереди.
- `weight-100/page-001.json` и др.: максимум 40 записей, ID, лемма, категории, вес, исходные статусы, наличие звуков, число изображений, типы связей.
- `queues/<task-id>/page-001.json`: краткие списки для конкретной работы, сортировка по весу и ID.
- `tasks.json`: правила отбора и редакторские ограничения. 

В новом сеансе сначала проверить `source.master.sha256` в manifest индекса против `source_sha256` в `outputs/library-modules/manifest.json` из актуального main. SHA-1 в `master.git_blob` относится к логическому снимку, а не к удалённому файлу. Если хэши расходятся, индекс устарел. Не продолжать по старому номеру страницы: после изменений состав очереди может измениться, поэтому рабочий пакет фиксируется по ID и ожидаемым значениям. Не считать количество связей полнотой семантики, отсутствие картинки обязательным пробелом, наличие машинного разбора его утверждением. Слоговые группы выводятся лишь при совпадении обоих хэшей источников. Отдельная ветка иностранных языков не включена в статистику main; необходима сверка. 

Тесты: `node --experimental-strip-types --test tests/library-toolkit.test.ts tests/library-index.test.ts`. Публикация сайта остаётся за действующим workflow. Никакого автоматического применения патчей на этом этапе.
