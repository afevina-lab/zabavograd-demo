# Удалённый лингвистический анализ из обычного чата

Используется канонический main:outputs/library-modules. Запрос — только данные, не код.
Создать новую ветку library-analysis-request/<slug> от актуального main, записать
editorial/requests/library-analysis.json без [skip ci]. Источник фиксируется логическим SHA
из outputs/library-modules/manifest.json. Workflow читает код и библиотеку из main,
запрос из точного коммита ветки. Пример:

```json
{"version":1,"source_sha256":"<64 hex>","mode":"initial","domain":"both","weight":100,"limit":100,"validate_candidate":false}
```

Режимы:
- initial: только отсутствующие поля; domain both/morphology/phonetics; расширенные
  парадигмы через существующий pymorphy3, фонетика Russian G2P из фиксированной ревизии.
- extend: недостающие ключи существующих предложений через extend-morphology; без
  перезаписи утверждённых форм. Фильтры weight, part_of_speech, category, limit (1–2500).
- constructicon: предложения из закреплённой CC BY 4.0 базы, полный словарь, без фильтров.
  Не публиковать или активировать предложения без проверки атрибуции.
- framebank: отдельный GPL-3.0 пакет предложений управления и валентности с лицензией, атрибуцией и ссылкой на исходную ревизию. Не смешивать с игровыми данными; не утверждать автоматически.
- ruwordnet: скачивание базы в одноразовом runner, статистика покрытия и неоднозначности. На публичной ветке только агрегаты: официальный сайт одновременно указывает CC BY-SA 4.0 и некоммерческое распространение. Подробные сопоставления и связи остаются вне публичной выгрузки до уточнения условий и проверки смысла.
- Wikidata: требуется отдельно подготовить точное сопоставление QID и ID; пока не включён.

Результат: library-analysis-result/<slug>-<12 символов SHA запроса>, result.json,
analysis-report.json и при наличии изменений delta/ с манифестом и только изменёнными
модулями. Полный машинный отчёт initial тоже доступен. В режиме constructicon — suggestions.json, framebank — отдельный framebank-gpl/ с лицензией, ruwordnet — coverage.json. Для этих трёх режимов достаточно version, source_sha256, mode.
Отдельная задача публикации не запускает анализаторы с правом записи. Никаких изменений main,
gh-pages, активных изображений или существующих утверждений. Если validate_candidate=false
(по умолчанию), выполняются только защита архива, схема и проверяемый roundtrip.
validate_candidate=true добавляет полный библиотечный валидатор, не CI сайта.
Не применять delta без сверки точного исходного SHA, воспроизведения и полной проверки;
результат анализа не является утверждением или публикацией. При изменении источника
повторить запрос. Ошибка установки или G2P — явный сбой, не успешная пустая выдача.
