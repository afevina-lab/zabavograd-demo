## Подготовлено

- `scripts/ci-plan.mjs`: классификация FAST / TARGETED / FULL, затронутые игры, темы, размеры и объяснение причин.
- Общие компоненты включают всех пяти потребителей; тема ограничивает темы, но не потребителей. Общая модель не считается локальной зависимостью мемори.
- Неизвестные пути, отсутствие списка изменений, глобальный CSS и инфраструктура требуют FULL. Ручной режим может только повысить рассчитанный риск.
- Девять тестов, включая запуск CLI. Отдельный workflow рабочей ветки проверяет маршрутизацию и сохраняет предложенный план, без прав на запись и без деплоя.

Это прототип выбора проверок, а не завершённая оптимизация: выбранные браузерные сценарии пока не запускаются по этому плану. Экономия времени ещё не заявляется.

## Второй этап: исполняемый процесс без публикации

Общие проверки выполняются один раз: архитектура, синхронизация, библиотека, дизайн-система, 193 теста, TypeScript. Одна сборка и проверка автономности сохраняются вместе с планом и SHA; браузерные задания проверяют SHA и используют этот же артефакт. Три темы запускаются параллельно, максимум три задания. Кешируются загрузки npm и pip, установка сохраняется.

FAST проверяет маршруты настроек, видимые изображения, границы и наличие запуска. TARGETED дополнительно выполняет существующие проверки настроек выбранных игр и размеров, сохраняя общие дополнительные сценарии. FULL сохраняет полные проверки настроек и игрового процесса для всех тем; отдельная проверка общей геометрии выполняется один раз. FAST также запускает игру и проверяет паузу/продолжение через реальные элементы интерфейса. Полное прохождение остаётся в FULL.

Исправлена устаревшая проверка конвейера: после добавления числа раундов нельзя требовать один числовой ввод на всей странице. Проверяются отдельные счётчики: числовое поле, ползунок, согласованность значений, отсутствие дублирующего output. Удалён уже использованный одноразовый workflow публикации, конфликтовавший с проверкой единственного издателя. Действующий visual-publish.yml не изменён.
