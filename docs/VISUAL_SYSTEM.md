# Единая визуальная система «Забавограда»

**Единственный редактируемый репозиторий визуала:** [afevina-lab/zabavograd-demo](https://github.com/afevina-lab/zabavograd-demo), ветка `main`. 
Ветка `gh-pages` — опубликованная собранная версия; вручную переписывать в ней CSS и JS нельзя.

## Один контракт для всех игр

- `src/design-system/themes.ts`: нейтральная, лесная и космическая темы; палитра, ссылки на подвижные WebP, карточки, шапка.
- `src/design-system/theme.css`: фон, прозрачные карточки, полноширинная шапка, контраст текста, рамки окон.
- `src/design-system/controls.css`: общие состояния кнопок и пиктограммы.
- `src/design-system/motion.ts` и `motion.css`: одни времена и анимации; две синхронные стадии найденной пары: **зум → акварельный хлопок**. Никогда не уменьшать насыщенность.
- `src/styles/layout.css`: только общая геометрия и адаптивная раскладка.
- `src/design-system/SceneLayers.tsx`: отдельные деревья, листья, планеты; анимации задаёт реестр.
- `src/GameUI.tsx`: общие наградные звёзды, подбор тем и иконки; обе игры используют одинаковые кнопки «Домой» и «Подписи».

## Качество арта

Нейтральный фон: `assets/neutral/approved-paper-4k.webp`, без уменьшения разрешения.
Лес: отдельные WebP деревьев, папоротника, куста, ковра цветов и падающих листьев; общий `forest_background.webp`.
Карточки: целый WebP, **не** nine-slice. Сырой лесной WebP включает бумажные углы с фоном: `scripts/prepare-card-skins.py` убирает **только связанный с внешней границей бумажный фон**, сохраняя бумагу внутри рамки. Готовые WebP публикуются с альфа-каналом. Искажение цвета и десатурация запрещены.

## Запреты

Не создавать `forest-memory.css`, `space-sorting.css`, отдельные патчи после сборки, второй набор пиктограмм, локальные длительности анимации. Логика тем не должна появляться в игровых правилах. Словарные данные и редакторские генераторы остаются в своём потоке; публичный фронтенд читает только уже опубликованный `library.json`.

## Проверки

`npm test` — логика игр и тесты темы; `npm run check:design-system` — архитектура и наличие ассетов; `npm run build` — TypeScript и Vite; `python scripts/prepare-card-skins.py dist` — настоящая прозрачность округлых углов; `node scripts/verify-ui-browser.mjs` — Chrome, несколько размеров и обе игры. CI выполняет всё перед обновлением `gh-pages`.
