# Исправления общей основы конструктора

База: `5dcbca5ba5239479096c481a303c2c62f9f85ea5` в main публичного репозитория.

- Общий loadLibrary проверяет HTTP-ответ и минимальную структуру runtime-записей, уникальность ID и конечность весов. Общий useLibrary обрабатывает отмену загрузки и сообщения об ошибке для всех трёх игр. Отменённый запрос не обновляет состояние компонента.
- learningPool сохраняет разные значения с одинаковым написанием по ID. Только Мемори с текстовыми лицевыми сторонами отдельно исключает неразличимые надписи; режим картинка-картинка сохраняет разные значения. Источник библиотеки не меняется.
- balancedPick использует общую проверку автоматического допуска.
- Исправлен селектор карточки сортировки при последовательной проверке ответа.
- Сборка останавливается при отсутствии outputs/library-v2.json, вместо подмены источника производным library.json.
- Архитектурная проверка запрещает fetch внутри TSX-компонентов. Новые обычные TS-модули автоматически относятся к доменному слою; адаптеры перечислены явно.

Проверены 73 теста, TypeScript, сборка, контракт библиотеки и дизайн-система. CSS и данные библиотеки не изменены. Дальнейшие задачи: полная модель форм и типизированных отношений, выделение регистрации игр и общих звуков/таймеров, фиксация зависимостей. Эти задачи не считаются выполненными данным изменением.
