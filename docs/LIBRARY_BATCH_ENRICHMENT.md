# Пакетное пополнение существующей библиотеки
Из чата создать ветку library-apply-request/<slug> от main и записать editorial/requests/library-batch.json:
{"version":1,"mode":"apply_standard","source_sha256":"<точный логический SHA манифеста>"}.
GitHub Actions запускает внешние анализаторы в отдельном runner; объединяет новые поля, не переписывает утверждённые данные, помечает неоднозначные варианты review_required=true и сохраняет в external_linguistic_proposals.
Точные формы pymorphy3 допускаются только через существующий safe subset; не включать непроверенный счёт. G2P действует по прежним ограничениям совпадения звука и буквы.
Смысловые связи автоматически активны только для независимо подтверждённых обычных фактов из library-standard-relations.cjs; остальные остаются предложениями. Грамматические конструкции FrameBank требуют проверки значения, типичности участников и независимого авторства; не выдаются как готовые игровые модели.
Проверяются архив, стабильные ID, схема, модульный roundtrip, граф без циклов, полный библиотечный валидатор и runtime export. Без браузерных тестов и перестройки визуала. Коммит выполняется в main только при точном исходном SHA и fast-forward. Сайт отдельно публикуется штатным издателем; изменения не считать опубликованными до его подтверждения.
