# Многоязычная библиотека — пилот (22 ноября 2026)

**Статус:** подготовлен отдельный рабочий контур. Данные не утверждены и не участвуют в играх.

## Границы и канонический источник
- Каноническая русская редакторская библиотека: `outputs/library-v2.json`, существующие ID не переименовываются.
- `library.json`, `semantic-graph.json` и `public/grammar-frames.json` — производные, напрямую не редактировать.
- Этот пилот пока **не вводит** новую основную библиотеку и не публикует иностранную лексику.
- Языки: `en`, `fr`, `es`, `de`. Временные импортированные записи проверяются по `schemas/multilingual-candidates.schema.json`.
- Запись иностранной лексемы не равна понятию: один перевод может относиться к нескольким значениям, а одно значение — к нескольким словам.
- Связь с русской карточкой хранится по существующему `library_entry_id`, по возможности с `library_sense_id`. Нельзя соединять слова только по написанию или единственному переводу.

## Правила внедрения
1. Перед миграцией сохранить SHA основной ветки и `gh-pages`, проверить состояние Actions; отдельная ветка пилота защищает `main` от неготовых изменений.
2. Найти соответствия утверждённым русским значениям; неизвестные понятия предлагать как новые, но не создавать автоматически в V2.
3. Импортировать Kaikki/Wiktionary, Open Multilingual Wordnet, UniMorph и при необходимости ConceptNet во **временный процесс**, а не в клиент сайта.
4. У каждой записи сохранять источник, точный тип лицензии, дату, исходный идентификатор, статус проверки. Проверить совместимость лицензий до включения в публичную производную базу.
5. Фиксировать формы и IPA с указанием достоверности, варианта языка и источника; CEFR без проверенного источника не заполнять.
6. Использовать `suggested` для импортированных гипотез. Игровые экспортеры должны принимать только `verified` и только после отдельного включения поддержки выбранного языка.
7. Сначала провести ручную сверку 100–200 существующих русских значений во всех четырёх языках, отдельно проверить омонимы и частичные совпадения. Затем тестировать полноценную интеграцию.
