# Проверки и публикация по риску

Единый workflow visual-publish.yml, план scripts/ci-plan.mjs. PR сравнивается с точным base SHA; main — с исходным SHA реально собранной gh-pages из index.html. Неизвестный, пустой или невалидный diff и любое изменение общих файлов/сборки/скриптов/JSON вне явного списка — FULL. Ручной запуск FULL по умолчанию.

| Режим | Обязательные проверки |
| --- | --- |
| DOCS | Планировщик и git diff --check; без сборки, browser и публикации. На main сверить существующий релиз. |
| LIBRARY | Все статические и unit проверки, валидаторы, синхронизация runtime один раз, WebP изменённых слов, сборка, offline, краткий браузер всех игр и поиск/материалы. |
| GAME | Те же обязательные статические проверки, scoped critical/settings только изменённые изолированные экраны игр; общий код и main.tsx — FULL. |
| THEME | Те же обязательные проверки, critical/settings/dialogs только изменённые темы. |
| FULL | Все прежние browser-проверки, три темы, все размеры, полный набор общих регрессий. |

Сборка использует публичный base /zabavograd-demo/ сразу; HTTP-пробы обслуживают именно этот префикс. Публикуется тот же dist, без повторной сборки. Отдельный offline-release оставлен для gh-pages и ручной проверки; в main offline уже проверен в publisher. PR не публикует. Перед push проверить, что main не опередил проверенный SHA. Не отменять выполняющийся релиз новым PR. Никаких изменений визуальной ветки.
