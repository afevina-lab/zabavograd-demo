# Отбор звуков, исключения и близкие отвлекающие карточки

## Клинический смысл

**Целевые звуки** и **исключаемые звуки** — два разных набора. Исключённый звук не может одновременно быть целевым. По умолчанию редактор предлагает **возможные типичные смешения**, а не устанавливает диагноз ребёнку. Логопед может снять любую отметку или вернуть рекомендации; его ручное решение не должно самопроизвольно отменяться при смене звука.

При автоматизации исключения строго удаляют материал с соответствующими фонемами. В **Конвейере с условием** исключённый звук может встретиться именно в **неподходящей** карточке: это осознанная проверка отличия, а не автоматизация. Текст настройки предупреждает об этом. Если педагог не хочет даже предъявления смешиваемого звука, следует выбрать обычный режим без проверки (тогда неподходящих карточек нет).

Утверждённые фонетические разборы и ограничения на оглушение, контекстное смягчение, стечения и написание **сохраняются**. Близость отвлекающего материала определяется по фонемам, а не по буквам.

## Группы риска для выбора исключений

- Соноры: **Л — Ль / Р / Рь / В / Вь / Й**, **Ль — Л / Рь / Й / Вь**; **Р — Л / Ль / Рь / Й**. Замены Л→В, Л→Г, Л→Д, Л→Н встречаются при параламбдацизме, но конкретный набор определяется речью ребёнка, а не списком на все случаи.
- Свистящие и шипящие: **С — Ш / Сь / З / Ц / Щ / Ф**, **З — Ж / С**, **Сь — Щ / Ц / Ч / Фь**, **Ш — С / Ж / Щ**, **Ж — З / Ш**, **Щ — Сь / Ш / Ч**, **Ч — Ть / Щ / Ц / Сь**.
- Звонкость: **Б—П, В—Ф, Г—К, Д—Т, Ж—Ш, З—С**; для мягких согласных соответствующие мягкие оппозиции.
- Другие различения: **С—Ц, Т—Ц, Ть—Ч, К—Х, Ль—Й**; для гласных **А—О, О—У, Ы—И**. Твёрдость/мягкость по наблюдаемому смешению.

Стандартные рекомендации в `src/learning.ts` намеренно компактнее всех возможных клинических замен: слишком широкая автоматическая блокировка исключала бы нужные слова. Встречающиеся индивидуальные замены логопед добавляет вручную.

## Пропорции игровых карточек

- Если одновременно включены слова и слоги, общий отбор в **Мемори**, **Сортировке** и **Конвейере** стремится к соотношению **50:50**, с отклонением на одну карточку при нечётном количестве; если материала одного типа не хватает, недостающее заполняет второй тип. Без повторения ID.
- В **Конвейере с проверкой** неподходящих карточек **не более 40%**, распределение по порядку перемешано. Режим без проверки не создаёт искусственно неправильных карточек.
- Внутри неподходящих при наличии достаточного материала минимум **70%** выбирается из близких контрастов: для звуков — с типично смешиваемыми фонемами, для лексики — из соседних категорий и веток той же крупной темы. Остальные — разнообразные. Если близких карточек недостаточно, механизм использует доступные другие: точное 70% невозможно гарантировать без выдумывания слов.
- Подходящие и неподходящие карточки отбираются из реального библиотечного материала без повторения ID и одинаковых подписей в одном задании.
- Педагогические веса и индивидуальные ограничения используются как прежде; правила общие, а не отдельные копии для каждой игры.
