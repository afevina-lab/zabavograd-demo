# Отбор звуков, исключения и близкие отвлекающие карточки

## Клинический смысл

**Целевые звуки** и **исключаемые звуки** — два разных набора. Исключённый звук не может одновременно быть целевым. По умолчанию редактор предлагает **возможные типичные смешения**, а не устанавливает диагноз ребёнку. Логопед может снять любую отметку или вернуть рекомендации; его ручное решение не должно самопроизвольно отменяться при смене звука.

При автоматизации исключения строго удаляют материал с соответствующими фонемами. Рекомендации по исключению (в том числе звуков позднего онтогенеза) **не равнозначны** близким фонематическим парам: в Конвейере для 70% похожих отвлекающих карточек используются только звуковые оппозиции, а не весь список педагогических исключений.

В **Конвейере с условием** исключённый звук может встретиться именно в **неподходящей** карточке: это осознанная проверка отличия, а не автоматизация. Текст настройки предупреждает об этом. Если педагог не хочет даже предъявления смешиваемого звука, следует выбрать обычный режим без проверки (тогда неподходящих карточек нет).

Утверждённые фонетические разборы и ограничения на оглушение, контекстное смягчение, стечения и написание **сохраняются**. Близость отвлекающего материала определяется по фонемам, а не по буквам.

## Группы рекомендуемых исключений (16 ноября 2026)

Рекомендации **объединяются по общим правилам**, а не настраиваются отдельно для каждой игры.

- **С и Сь:** добавить Ж к существующим оппозициям; **З и Зь:** дополнительно Ш, Ч, Щ.
- **Любой свистящий** (С, Сь, З, Зь, Ц): дополнительно Р, Рь, Л. Это педагогическая настройка на случай, когда соноры ещё не поставлены, **а не** утверждение о смешении каждого из них со свистящими.
- **Любой шипящий** (Ш, Ж, Ч, Щ): исключать **все свистящие** (С, Сь, З, Зь, Ц), сохраняя частные оппозиции (например, Ть—Ч).
- **При автоматизации звуков раннего онтогенеза** (все гласные и группа «Ранний онтогенез» в редакторе): рекомендовать исключать **все поздние** — свистящие, шипящие, аффрикаты и соноры. В текущей структуре группы поздних: С, Сь, З, Зь, Ц, Ш, Ж, Ч, Щ, Й, Р, Рь, Л, Ль.
- Сохраняются прежние базовые рекомендации: сонорные **Л — Ль / Р / Рь / В / Вь / Й**, **Ль — Л / Рь / Й / Вь**, **Р — Л / Ль / Рь / Й**; звонкость **Б—П, В—Ф, Г—К, Д—Т, Ж—Ш, З—С**; частные **С—Ф, С—Ц, Ть—Ч, К—Х, Ль—Й**, гласные **А—О, О—У, Ы—И**.

Для проекта **Й отнесён к поздней группе** вместе с сонорами, хотя в разных возрастных классификациях он может рассматриваться как рано формирующийся. Это **условное правило редактора**, которое педагог вправе изменить. Деление на ранние и поздние звуки не означает, что ребёнок обязательно испытывает затруднения со всеми поздними звуками. Особенно при комплексном исключении возможен существенный дефицит слов; педагог снимает ненужные ограничения вручную. При многозвуковом выборе рекомендации объединяются, целевые звуки не исключаются.

## Пропорции игровых карточек

- Если одновременно включены слова и слоги, общий отбор в **Мемори**, **Сортировке** и **Конвейере** стремится к соотношению **50:50**, с отклонением на одну карточку при нечётном количестве; если материала одного типа не хватает, недостающее заполняет второй тип. Без повторения ID.
- В **Конвейере с проверкой** неподходящих карточек **не более 40%**, распределение по порядку перемешано. Режим без проверки не создаёт искусственно неправильных карточек.
- Внутри неподходящих при наличии достаточного материала минимум **70%** выбирается из близких контрастов: для звуков — с типично смешиваемыми фонемами, для лексики — из соседних категорий и веток той же крупной темы. Остальные — разнообразные. Если близких карточек недостаточно, механизм использует доступные другие: точное 70% невозможно гарантировать без выдумывания слов.
- Подходящие и неподходящие карточки отбираются из реального библиотечного материала без повторения ID и одинаковых подписей в одном задании.
- Педагогические веса и индивидуальные ограничения используются как прежде; правила общие, а не отдельные копии для каждой игры.
