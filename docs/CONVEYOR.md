# Конвейер

Вход: `?game=conveyor`, ссылка в игровой мастерской. Данные, темы и MaterialSettings общие с остальными играми. Речевой ответ остаётся устным, распознавания речи нет.

Материал: картинки/слова из общей библиотеки, буквы русского алфавита, примеры сложения и вычитания без отрицательных результатов в пределах 10/20/100.

Без условия педагог оценивает называние/чтение/решение. С условием автоматически сравнивается решение подходит/не подходит: выбранные критерии материала, целевая буква, истинность равенства либо отсутствие случайных ошибок. Орфограммы не реализованы. Произвольные предметные условия и перевод пока не генерируются автоматически.

Простой уровень останавливается посередине до отметки. Средний и сложный непрерывно движутся, выпускают следующую карточку при пересечении центра предыдущей; прирост скорости ограничен 20%. Карточка без отметки считается пропущенной, а не неправильной. Галочка/крестик относятся к самой ранней неотмеченной карточке, достигшей центра; повторная отметка блокируется. При уходе вкладки в фон игра ставится на паузу.

Случайные ошибки (пропуск, вставка, замена, смешанный режим; 1–2 операции) существуют только в задании. Исходное слово не меняется. Вариант не принимается, если совпал с другим словом библиотеки. Это техническая генерация ошибок, а не подтверждённый лингвистический анализ. После ответа показывается оригинал. В примерах после ответа показывается вычисленный результат.

Настройки фиксируются при запуске; новая настройка требует возврата из занятия. Условный отбор требует как подходящих, так и неподходящих карточек, иначе запуск блокируется. Исключения звуков сохраняются глобально: отрицательные примеры не обходят запрет.

Обновление по последнему решению автора: ответ доступен сразу; карточка после отметки ускоренно уходит. Счёт показывает только правильные ответы из общего количества. В конце используются общие звёзды. Текстовая оценка ответа и линия центра убраны. Без условия базовая скорость удвоена; ускорение среднего/сложного уровня достигает 50% к концу последовательности. Число ошибок определяется длиной: 1 для 2–6 букв, 2 начиная с 7; проверяется фактическое расстояние редактирования, чтобы операции не отменяли друг друга. Материал выводится из учебной задачи, отдельного выбора материала нет. Старые описания скорости и ожидания центра выше относятся к предыдущему выпуску.

В режиме «Работа со звуками → Подходит к заданию?» проверка использует фонемный состав независимо от пригодности для автоматизации: ответ «да» получают слова с целевым звуком без выбранных исключённых звуков; ответ «нет» — слова с выбранным оппозиционным звуком и без целевого. Слова с обоими типами звуков исключаются из раунда. В этом режиме среди карточек ориентировочно 60% контрастных ответов «нет» при достаточном материале; прежний лимит 40% сохраняется для остальных условий. Настройки исключаемых звуков изменяются педагогом.

Оппозиционный материал настраивается независимо от исключаемых звуков: по умолчанию используется узкая пара (`С—Ш`, `Р—Л`), либо педагог выбирает контрастные звуки или лексическую тему. Исключение для автоматизации (например, `Р` при отработке `С`) не становится автоматически отрицательным ответом. Слова с целевым звуком и любым выбранным исключаемым звуком в том же слове не показываются.
