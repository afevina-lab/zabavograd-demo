# Визуальная система «Забавоград»

`main` публичного репозитория — единственное место исходного кода сайта, тем и анимаций. `gh-pages` — только автоматически сформированная публикация. Не править скомпилированные JS/CSS, не создавать тематических CSS-патчей.

- `src/design-system/themes.ts` — конфигурация фоновых изображений, карточек и UI-палитры каждой темы;
- `src/design-system/theme.css` — общее оформление карточек, окон и шапки;
- `src/design-system/controls.css` — единые кнопки;
- `src/design-system/motion.ts` и `motion.css` — общий язык движения и «акварельный хлопок»;
- `src/styles/layout.css` — только геометрия и адаптивная раскладка.

Сайт использует **уже публичный** `library.json`, приватные инструменты и редакторские файлы в этот репозиторий не переносятся.

`npm install && npm run dev`, `npm test`, `npm run check:design-system`, `npm run build`.
