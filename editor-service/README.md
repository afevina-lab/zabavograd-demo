# Веб-редактор библиотеки

Страница: https://afevina-lab.github.io/zabavograd-demo/editor/

Редактор читает актуальный `outputs/library-v2.json` из main. Не изменяет собранный library.json самостоятельно. Есть поиск, ветки, семь сортировок с направлением, просмотр всех полей, формы редактирования, добавление значений и веток, назначение существующих связей, экспорт/импорт черновика. Новые связи и машинные кандидаты не утверждаются автоматически.

## Однократное подключение входа и анализа

GitHub Pages не исполняет сервер. Разместите сервис из `editor-service/Dockerfile` на хостинге Docker с HTTPS. Например, в Render создайте Web Service из этого репозитория, выберите Docker, путь Dockerfile `editor-service/Dockerfile`, контекст `.`. Стоимость и условия выбранного тарифа проверяйте до создания. Пример настроек: `editor-service/render.yaml`.

1. После получения адреса сервера откройте https://github.com/settings/applications/new . Название: «Забавоград — редактор». Homepage URL: https://afevina-lab.github.io/zabavograd-demo/editor/ . Callback URL: `https://АДРЕС-СЕРВЕРА/auth/callback`.
2. В настройках сервера задайте `SERVICE_URL` (HTTPS-адрес без конечного /), `GITHUB_CLIENT_ID` и секрет `GITHUB_CLIENT_SECRET`. Секрет вводите только в защищённое поле хостинга, не в чат и не в Git.
3. Укажите адрес сервера в разделе «Подключение» редактора. Нажмите «Войти через GitHub». Разрешение public_repo используется только для указанного публичного репозитория; сервер проверяет права записи. Доступ действует час, токен GitHub остаётся на сервере в памяти. После перезапуска требуется новый вход.
4. Сохранение создаёт отдельную ветку и pull request. После проверки примите изменения на GitHub. Публикация производится существующим workflow; успешный PR не означает успешную публикацию.

Анализатор: pymorphy3 (MIT), словарь OpenCorpora; результаты сохраняются с указанием источника, только как suggested и unusable for generation. Автоматического определения смысловых связей и подтверждения фонетики нет. За один запрос — до 50 слов. Нужна авторизация.

## Проверки и ограничения

`node --test editor-service/model.test.mjs`. Docker запускает Node 24 и Python с pymorphy3 2.0.6. Реальный OAuth-вход, создание PR и серверный анализ требуют размещённого сервера и настроенных секретов; до этого доступны чтение, редактирование и скачивание черновика.

Существующие проверки проекта содержат исторически фиксированные количества и значения. Редакторские правки, затрагивающие такие условия, могут потребовать обновления соответствующего контрольного сценария в PR; редактор не отключает эти проверки. Архив legacy_source не предназначен для ручного исправления; менять его не нужно.

Несохранённые правки находятся в памяти вкладки. Перед закрытием скачайте черновик. При изменении main сохранение блокируется до сверки. Нельзя удалять существующие ID. JSON позволяет править сложные структуры; обычные поля доступны без него.
