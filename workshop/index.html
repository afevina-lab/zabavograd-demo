Ваша первая сцена

  1. Добавьте рисунки

    Слева откройте «Добавить рисунок» и нажмите на изображение.

  2. Расставьте предметы

    Перетаскивайте их по холсту, меняйте размер за угол. Справа доступны точные значения.

  3. Проверьте экраны

    Выберите телефон, планшет или ноутбук над холстом. «Адаптация» задаёт поведение предмета.

  4. Скачайте документ-код

    Передайте полученный JSON в чат для переноса в публичную библиотеку.

Черновики хранятся только в этом браузере. Скачивайте документ для резервной копии.
